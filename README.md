# English for Two

אפליקציית אינטרנט לתרגול אנגלית לשניים (רפאל ושני), בדיבור ובכתיבה. בלי שרת ובלי AI: כל התוכן כתוב מראש בקובץ אחד, וההתקדמות של כל אחד נשמרת בטלפון שלו.

## מה יש בפנים
- **סצנות אינטראקטיביות:** שיחות עם בחירות (בלחיצה או בדיבור) ומשוב על כל בחירה.
- **תרגול:** בחירת משמעות, השלמת משפט, סידור משפט מאריחים, מציאת טעות, ואמירה בקול.
- **דו-קרב זוגי:** אותן שאלות לשניכם בטלפון אחד, בתורות.
- **מחסן מילים:** חזרה במרווחים (Leitner), מילים נשמרות מסצנות ומתרגילים שטעיתם בהם.
- **סשן של 5 או 20 דקות,** XP, רמות ורצף ימים לכל אחד.

## קבצים
- `index.html` — האפליקציה כולה (HTML, CSS, JS ותוכן).
- `manifest.webmanifest`, `icon.svg`, `sw.js` — התקנה כאפליקציה ועבודה בלי רשת.

## הרצה בטלפון
1. מפעילים GitHub Pages על הענף `main` (Settings > Pages).
2. פותחים את הקישור בטלפון: Safari באייפון, Chrome באנדרואיד.
3. מוסיפים למסך הבית (Share > Add to Home Screen באייפון, או "התקן אפליקציה" באנדרואיד).

## דיבור
- **הקראה** עובדת בשני המכשירים.
- **זיהוי דיבור** עובד היטב ב-Chrome באנדרואיד. באייפון הוא מוגבל. אם הכפתור לא זמין, האפליקציה עוברת לדירוג עצמי, ואפשר להשתמש בהכתבה שבמקלדת.
